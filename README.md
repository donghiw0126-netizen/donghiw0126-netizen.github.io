# donghiw0126-netizen.github.io

GitHub Pages 맨 앞 주소(https://donghiw0126-netizen.github.io/)의 프로젝트 모음 페이지.

- 각 프로젝트(printcost-lab, daily-lights, daily-log)는 자기 저장소에서 따로 배포되고, 이 저장소는 모음 페이지·robots.txt·전체 sitemap.xml 만 담당
- 네이버 서치어드바이저는 호스트 단위 주소만 받아서, 인증 태그를 이 페이지(index.html)에 둠
- 배포: main 브랜치에 push 하면 GitHub Pages 가 바로 반영(빌드 없음)
- 새 프로젝트를 공개하면 index.html 카드와 sitemap.xml 에 추가
